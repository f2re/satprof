# Веб-интерфейс

OpenLayers использует отдельные слои спутников, TLE-трасс, гранул и выбранной точки. Сервер выбирает ближайшее поле зрения и ограничивает расстояние параметром `web.profile_max_distance_km`.

Профиль отображается SVG-графиком по логарифмической шкале давления и сохраняется в JSON. Панель состояния показывает очередь, число зондов/гранул/пар, результаты DWD/IGRA/WIS2 и текущее состояние MQTT-подписчика.

API источников: `GET /api/v1/sources`. Статус обновляется без перезагрузки каждые 15 секунд.

Для закрытого контура разместите OpenLayers и тайлы локально, затем замените CDN и OSM-source в `web/static`.
