# Веб-интерфейс

OpenLayers использует OSM и отдельные слои для TLE-трасс, спутников, гранул и выбранной точки. Сервер выбирает ближайшее поле зрения и ограничивает расстояние параметром `web.profile_max_distance_km`. Профиль выводится SVG-графиком по логарифмической шкале давления и может быть сохранён в JSON.

Для закрытого контура разместите OpenLayers и тайлы локально, затем замените CDN и OSM-source в `web/static`.
