# Источники радиозондирования

## Приоритеты

1. **WIS 2.0/GTS** — основной производственный поток минимальной задержки.
2. **DWD TEMP BUFR** — открытый оперативный резерв и контроль полноты.
3. **NOAA IGRA 2** — история, дозаполнение и независимые выборки.
4. **GRUAN** — метрологическая опора с вертикальными неопределённостями.
5. **ЕИП Росгидромета** — региональное дополнение после фиксации формата.

## WIS 2.0

`satprof-wis2` подписывается на Global Broker по MQTT v5, обрабатывает WIS2 Notification Message и загружает TEMP BUFR. Реализованы SHA-проверка, дедупликация по `data_id`, update/deletion, атомарная запись и постановка обработки. См. [WIS2.md](WIS2.md).

## DWD

Worker просматривает открытый каталог DWD, загружает последние BUFR и декодирует их через ecCodes. DWD можно оставить одновременно с WIS2: профили имеют устойчивый ключ станции и времени, поэтому одинаковые выпуски обновляются, а не размножаются.

## IGRA и GRUAN

IGRA предназначен для исторического обучения; станции указываются явно. GRUAN хранится как отдельный источник и используется для независимой валидации и оценки переноса неопределённости через Якобианы RTTOV.

## Метаданные

Сохраняются источник, WMO/WIGOS ID, время запуска, координаты/траектория, параметры по уровням, QC и SHA исходного файла. Источники нельзя смешивать без признака происхождения: смена прибора или алгоритма способна создать ложный скачок спутниковой поправки.
