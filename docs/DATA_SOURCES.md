# Источники радиозондов

1. **DWD TEMP BUFR** — основной бесплатный оперативный поток прототипа.
2. **WIS 2.0/GTS** — предпочтительный производственный поток минимальной задержки.
3. **NOAA IGRA 2.2** — глобальная история и дозаполнение.
4. **GRUAN** — опорные исправленные профили с неопределённостями.
5. **ЕИП Росгидромета** — региональное дополнение после фиксации формата ресурса.

Для каждого профиля сохраняются источник, WIGOS/WMO ID, тип зонда, версия обработки, время выпуска и траектория. Источники нельзя смешивать без этих признаков: смена прибора или алгоритма может создать ложный скачок спутниковой поправки.
