# Проверка

Автоматически проверены IGRA, физические преобразования, траектория шара, 4D-коллокация, bias-модель, очередь, Level‑1C NetCDF, выбор ближайшего FOV, FastAPI, SatDump CLI-контракт и полный синтетический цикл.

На целевой системе требуется проверить локальные BUFR-дескрипторы, конкретный Level‑1C МТВЗА‑ГЯ/ИКФС‑2/МСУ‑ГС, PyRTTOV, SRF, эмиссию, облачный контроль и считыватель WRFDA. `DemoWeightedRTM` предназначен только для теста программного контура.
