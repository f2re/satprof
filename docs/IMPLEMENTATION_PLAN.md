# План внедрения

1. Зафиксировать Level‑1C, SRF, геометрию, калибровочные эпохи и коэффициенты RTTOV.
2. Подключить DWD/WIS2, IGRA и контрольную выборку GRUAN.
3. Накопить O−B в режиме мониторинга с разбивкой по каналу, скану, углу, поверхности, орбите и сезону.
4. Проверить коллокации вручную и оценить составляющие неопределённости.
5. Обучить статическую bias-модель и медленный дрейф на временном train/validation-разделении.
6. Обучить retrieval, оставив станции/периоды GRUAN независимыми.
7. Начать WRFDA с 1–2 устойчивых температурных каналов и только после месячного эксперимента расширять набор.

Минимум для кандидата: 40 независимых запусков и 80 пар на канал; для эксплуатации желательно 200–500 запусков на режим. Production-версия не должна ухудшать независимое RMSE и оставлять значимый residual bias.
